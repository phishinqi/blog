# 本地验证记录

## 功能与代码检查

在不含本地私人内容的干净检出上运行 `pnpm verify`（2026-09-29）：

- Astro/TypeScript 检查：0 错误、0 警告。
- ESLint 与 Prettier 检查通过。
- 单元测试：覆盖发布排除、slug、日期（含 `it.each` 参数化的非法/歧义日期与小写校验）、作者、分类、相册与照片字段、许可继承、照片 ID，以及模拟的 Pages Functions OAuth/R2 请求。EXIF 解析、只填空白的预填规则和图片处理管线随编辑器迁到了 v7-cms，在本仓库的测试中移除。
- 浏览器测试：覆盖真实 Pagefind 搜索、主题 / 语言菜单（含键盘操作）、目录迁移、多作者、封面、瀑布流排布与标签筛选、悬停放大、懒加载、查看器（缩放、滑动、深链接、返回键、焦点恢复）、页头滚动隐藏、页脚写作入口、移动端、无 JavaScript 和明暗主题无障碍。
- 本地写作实际读写：编辑器（v7-cms）在浏览器里通过 File System Access API 直接读写当前检出，没有本地代理进程。文章 Markdown / MDX、相册图片上传等编辑行为在编辑器仓库 `phishinqi/v7-cms` 自己的测试里验证；本仓库只验证 `/admin/` 路由能挂载编辑器、以及构建确实把 `v7-cms.js` 与 `cms.css` 复制到了 `public/admin/`。
- `pnpm test:variants` 验证了关闭全部模块和后台（包括 `/photos/` 与页脚写作入口）、默认英文、R2 媒体库与关闭 EXIF 预填的配置。该命令会临时修改站点设置并在结束时恢复，不要与手动修改配置同时运行。
- 生产构建输出 51 个页面，Pagefind 索引 12 篇公开示例文章。未发布示例不进入页面、RSS、sitemap 或搜索。
- 端口被占用时可设置 `V7_TEST_PORT`（预览，默认 4321）。

## 已知边界

- 没有真实 GitHub OAuth、远程草稿分支、正式发布或 R2 凭据联调；Pages Functions 的权限、上传和失败测试使用模拟服务。R2 上传界面未在浏览器中实际运行过。这些接口只在编辑器使用 `github` / `proxy` 后端或 R2 媒体库时才需要，默认的本地 `fs-access` 后端完全用不到它们。
- 触屏双指缩放只做了代码层面的实现，自动化测试覆盖了滑动切换，没有在真机上验证捏合手势。
- 自动化浏览器覆盖 Chromium；其他浏览器的兼容回退仍需发布前人工检查。
- Astro/MDX 构建仍给出 `use astro:head-inject` 指令提示，Mermaid 的按需依赖仍有大分块提示；未静默隐藏这些上游提示。MDX、公式、图表渲染和主题重绘测试通过。
- v7-cms 是独立仓库，不在本站依赖树内：本站只消费它发布的编译产物（`scripts/copy-cms.mjs` 拉取 `/admin/v7-cms.js` 与 `/admin/cms.css`），因此 `pnpm peers check` 不会因编辑器产生新的不匹配，编辑器的编辑行为也不在本仓库的测试范围内，只能在编辑器仓库自身验证。
- 主题代码和技术文档采用 MIT，文章及编辑内容不纳入代码许可。
